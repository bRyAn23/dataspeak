# Data Speak

Data Speak is an AI-assisted analytics platform for structured
business data developed as part of the MSIT Capstone Project.

## Core Architecture

- React + TypeScript Frontend
- Laravel Backend API
- PostgreSQL / Amazon RDS
- Redis / Queue
- Python / FastAPI Analytics Service
- AI Gateway
- Claim Validation
- Executive Report Generation

## Core Design Principle

Numerical calculations are performed deterministically.
Generative AI is used for interpretation rather than calculating
critical business numbers.

## Repository Structure

- `/frontend` – React application
- `/backend` – Laravel API
- `/analytics` – Python/FastAPI analytics
- `/database` – schemas and migrations
- `/docs` – requirements and design documentation
- `/tests` – testing artifacts
- `/docker` – development environment configuration
