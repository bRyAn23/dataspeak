# Unit 7 Figures: captions and interpretation

All figures are unedited captures taken on 2026-10-15 on the local development stack (application screenshots during the 15:35 run; terminal figures at 18:14 to 18:16, after a first set taken while the screen was locked came out black and was discarded) (figure 08's underlying defect evidence also cites a production read). Terminal figures are macOS screenshots of a real Terminal window; application figures are Playwright screenshots of the running React application. Each maps to an executed case.

**Figure 1.** *Test environment record.* `evidence/environment/figure-01-test-environment.png`. Terminal output of the environment script: commit `e5ecc93`, host and runtime versions, the seven running containers with loopback ports, and the four health checks. Interpretation: all services required by the test plan were healthy before execution; the record fixes the versions against which the results hold.

**Figure 2.** *Integration and system test results.* `evidence/integration/figure-02-integration-test-results.png`. Terminal listing of every recorded case with level, result, duration and the observed outcome, followed by totals after retests. Interpretation: 8 integration and 15 system cases pass; the five first-run failures (INT-07, SYS-04, SYS-05, SYS-12, LIM-01) are visible alongside their retests, showing how triage was recorded rather than hidden.

**Figure 3.** *Valid CSV workflow (SYS-02).* `evidence/system/figure-03-valid-csv-workflow.png`. The New analysis page after uploading the synthetic 240-row file: "File checked successfully, 240 rows and 7 columns detected" and the Continue to profile action. Interpretation: the client, API and analytics service completed validation in under a second and reported the counts that the golden dataset is known to have.

**Figure 4.** *Invalid CSV feedback (SYS-04).* `evidence/system/figure-04-invalid-csv-feedback.png`. The same page after uploading a file with an empty and a duplicated header: "The file could not be used", "1 column header(s) are empty", "region: Duplicate column header". Interpretation: structural errors stop the workflow with specific, readable reasons; the API returned 422 `CSV_VALIDATION_FAILED` (INT-05).

**Figure 5.** *Statistical validation (REG-01).* `evidence/regression/figure-05-statistical-validation.png`. Verbose pytest run of the golden-reference, output-validation and rule-selection tests: 17 passed. Interpretation: hand-verified and independently computed expected values for means, medians, sums, standard deviation, group aggregates, test selection and trend granularity still hold at the tested commit; the 33 individual assertions are itemised in `golden_reference_cases_2026-10-15.csv`.

**Figure 6.** *Performance test results (PERF-1..3).* `evidence/performance/figure-06-performance-test-results.png`. Terminal table of medians, p95, minima and maxima per scenario and dataset size, container resource snapshots, and the note explaining the small-dataset anomaly. Interpretation: deterministic processing scales roughly linearly and stays under 0.3 s for 10,000 rows; perceived latency comes from model calls and, in one case, from queue contention (DEF-04).

**Figure 7.** *Acceptance verification.* `evidence/acceptance/figure-07-acceptance-verification.png`. Terminal rendering of the acceptance checklist: twelve requirement-based criteria with procedure, expected and actual outcome, result and evidence reference. Interpretation: an investigator-led inspection, not user acceptance testing; all criteria met locally, two with documented exceptions (DEF-01, DEF-05).

**Figure 8.** *Defect or limitation (LIM-01 / DEF-05).* `evidence/system/figure-08-defect-or-limitation.png`. The Analyze page of a completed analysis: the panel says "or run again to recalculate from the current definitions" while the "Run again" button is disabled, because the transient CSV was purged after the run (API 409 `UPLOAD_REQUIRED`). Interpretation: the privacy rule is enforced and the system fails closed, but the interface does not explain the disabled control, which is logged as DEF-05.
